# Documentation du projet

Les dossiers de référence validés sont tenus à jour dans Claude Docs :

| Document | Contenu |
| --- | --- |
| Dossier d'analyse | Exigences fonctionnelles, rôles, cas d'utilisation, règles métier, périmètre du MVP |
| Dossier d'architecture | Architecture, modèle de données, API REST, pile technique, plan d'implémentation |
| Spécification UI/UX | Écrans, parcours, système de conception, accessibilité |

Ce dossier `docs/` accueillera les documents propres au dépôt : décisions techniques, procédures d'exploitation (déploiement, sauvegarde, restauration).

## Conventions

- **Code** (tables, colonnes, classes, fonctions, variables, adresses d'API) : en anglais.
- **Messages de commit** : en français, au format Conventional Commits.
- **Documentation** : en français.
